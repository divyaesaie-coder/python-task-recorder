# python-task-recorder
A simple Python task recorder that allows users to add tasks, view tasks, remove completed tasks, and store task records in a file.
# Python Task Recorder

A beginner-friendly Python project that manages daily tasks and stores them using file handling.

## Features
- Add tasks with completion status
- View all tasks
- Remove completed tasks
- Store task records in a text file
- Menu-driven console application

## Technologies Used
- Python 3
- File Handling

## How It Works
The program:
1. Takes task details from the user
2. Stores tasks in a list
3. Saves tasks into a text file
4. Displays task history
5. Removes completed tasks

## Concepts Used
- Lists
- Dictionaries
- File handling
- Loops
- if-else conditions
- User input handling
